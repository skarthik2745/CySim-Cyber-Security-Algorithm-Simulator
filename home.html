🔐 How It Works

  • Encryption: Scrambling readable data with a secret key so only authorized people can read it.
  • Decryption: Reversing the encryption process to unscramble data back to its original form using the correct key.
  • Encoding vs Hashing: Encoding translates data into a new format (reversible). Hashing creates a unique digital fingerprint (irreversible).
