Caesar Cipher

🏛️ What is the Caesar Cipher?

📖 Definition: One of the oldest encryption methods, named after Julius Caesar. It is a substitution cipher that replaces each letter with another letter a fixed number of positions down the alphabet.

⚙️ Working Principle: Imagine a dial with the alphabet. If your shift is 3:
• 'A' moves 3 spaces forward to become 'D'.
• 'B' becomes 'E'.
• 'Z' wraps around the dial to become 'C'.

💡 The Math (Modular Arithmetic): Computers use numbers for letters. The encryption formula is E(x) = (x + shift) mod 26. The "mod 26" acts like a clock, ensuring we wrap around when we go past 'Z'.

🛡️ Real World Application: Extremely weak today! It can be cracked instantly by trying all 25 possible shifts (Brute Force) or by analyzing common letters (Frequency Analysis). Mostly used as a learning tool.

Vigenère Cipher

🗝️ What is the Vigenère Cipher?

📖 Definition: An advanced version of the Caesar Cipher. Instead of using a single shift, it uses a keyword to change the shift for every single letter (a polyalphabetic substitution).

⚙️ Working Principle: If your message is HELLO and key is KEY:
1. Repeat the key: KEYKE
2. Shift 'H' by 'K' (10 spaces).
3. Shift 'E' by 'E' (4 spaces).
This hides repeating letters!

💡 Input Transformation: Historically, people used a "Tabula Recta" (a 26x26 grid of alphabets) to manually find the intersection of the message letter and the key letter.

🛡️ Real World Application: It was considered "le chiffre indéchiffrable" (unbreakable cipher) for 300 years until Charles Babbage cracked it in the 1800s using statistical analysis.

XOR Cipher

⚡ What is the XOR Cipher?

📖 Definition: XOR (Exclusive OR) is a logic operation inside CPU hardware. As a cipher, it combines the binary bits (0s and 1s) of your message with a secret key.

⚙️ Working Principle: The XOR rule:
• 0 ^ 0 = 0 (Same = 0)
• 1 ^ 1 = 0 (Same = 0)
• 1 ^ 0 = 1 (Different = 1)
• 0 ^ 1 = 1 (Different = 1)

💡 Input Transformation: XOR is perfectly symmetric! If you encrypt your message with a key, you just XOR the output with the exact same key to decrypt it: (Message ^ Key) ^ Key = Message.

🛡️ Real World Application: Incredibly fast and lightweight. XOR is the mathematical heart of modern, highly secure ciphers like AES (Advanced Encryption Standard) used by banks.

ROT13

🔄 What is ROT13?

📖 Definition: ROT13 ("Rotate by 13 places") is a specific variant of the Caesar Cipher. It shifts every letter by exactly 13 positions.

⚙️ Working Principle: Because the English alphabet has 26 letters, shifting by 13 is exactly half of the alphabet. 'A' becomes 'N', 'B' becomes 'O'... and 'N' becomes 'A'.

💡 Input Transformation: Applying ROT13 twice restores the original text. You don't need a separate "Decrypt" button—encryption and decryption are the exact same mathematical process!

🛡️ Real World Application: Not used for security! It was popularized on early internet forums to hide movie spoilers, punchlines, or offensive text from casual reading. A digital puzzle.

Reverse

⏪ What is Text Reversal?

📖 Definition: A simple string manipulation that flips the order of characters in a text. The last letter becomes the first, and the first becomes the last.

⚙️ Working Principle: The string "HELLO WORLD" is simply read backwards to become "DLROW OLLEH".

💡 Input Transformation: In programming, this is often done by converting text into an Array (a list of chars), running a reverse algorithm, and joining them back. A classic coding exercise!

🛡️ Real World Application: Not encryption! Used for checking Palindromes (words reading the same backwards, like "RACECAR"), formatting data, or basic obfuscation to bypass filters.

Atbash Cipher

🪞 What is the Atbash Cipher?

📖 Definition: Originally used to encode the Hebrew alphabet in biblical texts, Atbash is a substitution cipher that maps the alphabet to its exact reverse mirror.

⚙️ Working Principle: Think of it as folding the alphabet in half.
• 1st letter (A) swaps with 26th letter (Z).
• 2nd letter (B) swaps with 25th letter (Y).

💡 Input Transformation: If we map A=1 and Z=26, the underlying formula is New = 27 - Old. Like ROT13, Atbash is symmetrical. Apply it twice and you get your original text back.

🛡️ Real World Application: Purely historical and educational today. Often found in escape rooms, puzzle games, and amateur cryptography treasure hunts!

A ↔ Number System

🔤 Alphabet ↔ Number Mapping

📖 Definition: The process of converting alphabetical letters into their corresponding numerical positions.

⚙️ Working Principle: Different modes exist:
• A=1: How humans count (A=1, B=2 ... Z=26).
• A=0: How programmers count. Indexing at 0 makes crypto math flawless.
• Z=0: A reverse mapping.

💡 Input Transformation: Computers don't actually know what 'A' is! They use tables like ASCII, where the capital letter 'A' is internally stored as the decimal number 65, and lowercase 'a' is 97.

🛡️ Real World Application: Essential for building crypto algorithms from scratch, data serialization, and generating spreadsheet column headers (A, B, C... AA, AB).

Number System Converter

🔢 Number System Conversions

📖 Definition: Humans use Base-10 (Decimal) because we have 10 fingers. Computers use different mathematical bases depending on hardware constraints.

⚙️ Working Principle:
• Binary (Base-2): Uses 0 and 1 (Transistors OFF/ON).
• Octal (Base-8): Uses 0-7 (Old computer systems).
• Hexadecimal (Base-16): Uses 0-9 and A-F (Compact binary).

💡 Input Transformation: The letter 'A' is ASCII value 65. Under the hood, this translates to Decimal: 65 | Binary: 01000001 | Hex: 41.

🛡️ Real World Application: Hexadecimal is extensively used for Web Colors (e.g., #FF0000), Memory Addresses in debugging, and network MAC addresses.

Base64

📦 What is Base64 Encoding?

📖 Definition: Base64 is an encoding scheme (not encryption!). It takes raw binary data and translates it into a safe, standard text format using 64 printable characters.

⚙️ Working Principle:
1. Takes 3 bytes of data (24 bits).
2. Chops those 24 bits into 4 smaller chunks of 6 bits.
3. Maps those 6-bit chunks to safe characters (A-Z, a-z, 0-9, +, /).
4. Adds = padding at the end if the data doesn't divide evenly.

💡 Input Transformation: Internet protocols like Email were built to handle text, not images. Base64 safely disguises binary images as massive blocks of text so they can be transmitted without breaking!

🛡️ Real World Application: Email attachments, JWT (JSON Web Tokens) for website logins, and embedding tiny icons directly into HTML/CSS files (Data URIs).

SHA-256

🔒 What is SHA-256 Hashing?

📖 Definition: SHA-256 is a cryptographic hash function. Unlike encryption, hashing is a one-way street. You can scramble data into a hash, but you can never descramble a hash back into data.

⚙️ Working Principle:
• Deterministic: Same input always = same hash.
• Fixed Size: A 2-letter word or a 100GB movie both produce exactly 64 characters.
• Avalanche Effect: Changing ONE letter changes the entire output hash entirely.

💡 Input Transformation (Passwords): Websites NEVER store your actual password. They store the hash. When you log in, they hash what you typed and compare. Hackers only steal useless hashes!

🛡️ Real World Application: Securing passwords, verifying downloaded files, SSL/TLS web certificates, and it is the foundational math that runs the Bitcoin blockchain.
